The Complete Guide to Preparing a PDF for Job Applications

Your resume gets, on average, a few seconds of attention before a recruiter decides whether to keep reading. A poorly formatted PDF, a confusing filename, or a file that's oddly large can quietly work against you before anyone even reads your qualifications. This guide walks through everything you need to know to prepare application-ready PDFs — resumes, cover letters, and portfolios — that look professional and function correctly wherever they land.

Why PDF Is the Right Format for Job Applications

Word documents can look completely different depending on the software, version, and fonts installed on the device opening them. A resume that looks perfectly aligned on your computer might have shifted spacing, wrapped text, or a missing font when opened by a recruiter using different software.

PDF format locks your layout in place. Whatever you see when you finalize your document is exactly what the recruiter will see, regardless of their device, operating system, or software. This consistency is why PDF has become the standard expectation for professional documents in hiring processes.

After converting, open the resulting PDF and check that formatting, spacing, and any bullet points or tables appear exactly as intended. Minor differences can occasionally occur with complex layouts, so this quick check is worth doing before submitting anywhere.

Should You Combine Your Resume and Cover Letter?

This depends entirely on the application system you're using. Read the submission instructions carefully:

  • If the portal allows multiple file uploads — keep your resume and cover letter as separate files. This is generally preferred because it lets automated tracking systems parse each document correctly.
  • If the portal only allows one file upload — combine your cover letter and resume into a single PDF, with the cover letter first, using PDFECTA's Merge PDF tool.

When combining documents, make sure both files use consistent formatting — matching fonts and margins create a more polished, professional impression than two visually mismatched documents stitched together.

Naming Your Resume File Correctly

Recruiters and hiring managers often review dozens or hundreds of applications. A file named "resume.pdf" or "document1.pdf" gets lost among countless identical filenames from other applicants, and can make it harder to locate your file after downloading it.

Use a clear, professional naming convention instead:

  • FirstName-LastName-Resume.pdf
  • FirstName-LastName-CoverLetter.pdf
  • FirstName-LastName-Portfolio.pdf

This small detail signals attention to detail and makes it easier for anyone reviewing your application to keep track of your documents alongside dozens of others.

Keeping Your File Size Reasonable

Many application portals impose strict file size limits, often around 2-5MB per document. A resume with high-resolution images, unnecessary embedded fonts, or a scanned signature can sometimes balloon well beyond what's needed for a simple text document.

If your resume PDF is larger than expected, run it through PDFECTA's Compress PDF tool before submitting. A well-prepared resume should typically be well under 1MB — large file sizes for a document that's mostly text usually indicate an issue worth fixing.

Preparing a Portfolio PDF

If you're applying for a design, writing, or creative role, you may need to submit a portfolio alongside your resume. A few tips specific to portfolio PDFs:

  • Combine individual work samples into one cohesive document using Merge PDF rather than sending multiple separate files.
  • If your portfolio contains scanned or photographed work samples, use Rotate PDF to fix any sideways images.
  • Add page numbers with Add Page Numbers if your portfolio is long enough that reviewers might want to reference specific pages.
  • Compress the final file if it includes multiple images, since portfolios tend to be larger than text-only resumes.

Frequently Asked Questions

Should I submit my resume as a Word document or PDF?

PDF is generally safer. It preserves your exact formatting across every device, while a Word document can shift fonts and spacing depending on the software used to open it.

Should I combine my resume and cover letter into one PDF?

Check the job posting instructions. If multiple file uploads are allowed, keep them separate. If only one file is allowed, combine them into a single PDF in the correct reading order.

What should I name my resume PDF file?

Use a clear filename with your full name, such as FirstName-LastName-Resume.pdf, rather than generic names like resume.pdf.

How large should a resume PDF file be?

Typically under 1MB. Many portals have file size limits, and unnecessarily large files can indicate poor file preparation.
